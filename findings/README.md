# Security Findings

Completed findings will be added here as attack paths are validated.

Each finding will document:

- the security weakness and affected AWS service or permission
- enumeration and discovery steps
- the controlled attack path used in the CloudFoxable lab
- sanitized technical evidence
- realistic technical and business impact
- root cause
- remediation
- a retest showing whether the original path still succeeds

The reusable format is available in [the finding template](../templates/finding-template.md).

> Testing is limited to the intentionally vulnerable CloudFoxable resources deployed in my own AWS account.
